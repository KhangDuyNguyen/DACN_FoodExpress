# pages/customer - Web khách hàng (route `/`)

| Trang | Người làm |
|---|---|
| Đăng nhập/đăng ký, hồ sơ và địa chỉ, giỏ hàng, thanh toán | Khang |
| Trang chủ + tìm kiếm/lọc, chi tiết quán + menu, lịch sử đơn + đánh giá | Dưỡng |
| Theo dõi đơn có bản đồ | An |
| Chatbot, khu "Gợi ý cho bạn" | Điệp |

Mỗi trang tạo 1 file trong thư mục này, rồi thêm `<Route>` trong `src/App.tsx`.
